# Maintainers

## Current

- **Rodolfo Carrillo** — project owner and lead maintainer.

## Responsibilities

Maintainers are expected to:

- Review and merge pull requests.
- Keep CI, releases, and package metadata healthy.
- Triage issues and discussions.
- Handle security reports privately and promptly.
- Enforce the Code of Conduct.
- Keep documentation and ADRs current.

## Release authority

The project owner is the release authority while the maintainer team is small.
Releases are executed by CI only. A second maintainer should receive release
and registry access once the project has a stable 0.x release.

## Adding maintainers

Maintainers are added after sustained, high-quality contributions and lazy
consensus among existing maintainers. New maintainers must enable 2FA and
understand the DCO, release, and security processes.

## Emeritus

Inactive maintainers may be moved to emeritus status. Emeritus maintainers
retain recognition but lose merge and release permissions.
