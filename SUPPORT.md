# Support

OCPP Tools is maintained on a best-effort basis. There is no service-level
agreement or enterprise support commitment.

## Where to ask

- **Questions and ideas:** GitHub Discussions.
- **Bugs:** GitHub Issues with a minimal reproduction.
- **Security:** GitHub Private Vulnerability Reporting only.

## Before opening an issue

- Check the package README and the roadmap.
- Confirm the package, version, protocol version, Node version, and message
  type.
- Provide a minimal frame or payload that reproduces the problem.
- Redact CSMS URLs, credentials, certificates, idTag values, and production
  message IDs.

## Response expectations

Maintainers respond when time permits. Priority goes to security reports,
release-blocking bugs, and issues with clear reproductions.
