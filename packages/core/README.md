# @ocpptools/core

OCPP 1.6J/2.0.1 types, frames, parser/serializer, and transport interfaces.

> Status: skeleton. The package is wired for TypeScript, tests, and publishing,
> but the protocol API is not implemented yet.

## Scope

- OCPP frame types for CALL, CALLRESULT, and CALLERROR.
- Frame parsing and serialization.
- Version-aware OCPP error codes.
- Transport, clock, and storage interfaces.
- No Ajv, DOM, UI framework, or complete OCPP schemas.
