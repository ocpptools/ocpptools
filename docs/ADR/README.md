# Architecture Decision Records

Cross-package and architectural decisions are recorded here, as described in
[GOVERNANCE.md](../../GOVERNANCE.md). One file per decision, numbered in
order: `0001-short-title.md`.

Use [0000-template.md](0000-template.md) as the starting point. An ADR is
immutable once accepted. To change a decision, add a new ADR that supersedes
the old one and update the old one's status.
